# Casos Aprovados

Esta pasta armazenará exemplos de análises revisadas por especialistas.

Cada caso deverá registrar, no mínimo:

- dados de entrada relevantes;
- conclusão esperada;
- justificativa;
- ação sugerida, quando aplicável;
- validação do especialista;
- versão das regras utilizadas.

Esses casos servirão para avaliação do agente e, futuramente, como exemplos recuperáveis pelo RAG. Não incluir dados corporativos sensíveis no repositório público.
